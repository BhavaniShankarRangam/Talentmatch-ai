# TalentMatch AI

TalentMatch AI is a recruiter-facing candidate review dashboard. The standalone prototype demonstrates job-based candidate ranking, evidence-backed skill matching, configurable score filtering, candidate comparisons, and recruiter-controlled shortlisting using sample data.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required.

## Prototype scope

Candidate data and match scores are illustrative and are not generated by an AI service. Search, filters, comparison, and shortlist actions run in the browser. No candidate data is uploaded or persisted, and the prototype does not make hiring decisions.
